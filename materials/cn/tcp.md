# Chapter 5: TCP

<!-- page: 8 -->

TCP is a reliable, connection-oriented transport protocol.
A three-way handshake uses SYN, SYN-ACK, and ACK before data is sent.
A sequence number orders bytes so the receiver can detect loss.
UDP is connectionless and does not retransmit lost datagrams.
The port number identifies the application process on a host.
An IP address identifies the host, not the program.
