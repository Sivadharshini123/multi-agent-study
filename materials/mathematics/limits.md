# Chapter 1: Limits

<!-- page: 1 -->

A limit describes the value a function approaches as its input approaches a point.
The notation lim (x -> a) f(x) = L means f(x) gets close to L when x gets close to a.
A limit can exist even when f(a) itself is not defined.
If the left-hand limit and the right-hand limit are equal, the two-sided limit exists.
Polynomial functions are continuous, so the limit at a is f(a).
The derivative is a limit of a difference quotient.
