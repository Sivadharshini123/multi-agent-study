# Chapter 2: Ohm's law

<!-- page: 5 -->

Ohm's law states that voltage equals current times resistance.
The relation is written V = IR.
V is voltage in volts, I is current in amperes, and R is resistance in ohms.
If resistance stays constant, current rises when voltage rises.
A series circuit has one path, so the same current passes through each resistor.
Power in a resistor can be written P = VI.
